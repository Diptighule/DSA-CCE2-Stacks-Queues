# DSA CCE 2 – Stack and Queue Using Arrays

## Description
This repository contains C++ programs for implementing Stack and Queue using arrays as part of the Data Structures and Algorithms (DSA) CCE 2 assignment.

## Programs

### 1. Stack Using Array
Implements a stack using an array of maximum size 5.

**Operations:**
- Push – Inserts an element into the stack.
- Pop – Removes the top element.
- Peek – Returns the top element.
- Empty – Checks whether the stack is empty.
- Full – Checks whether the stack is full.
- Display – Displays the stack elements.

**Principle:** LIFO (Last In, First Out)

### 2. Queue Using Array
Implements a linear queue using an array of maximum size 5.

**Operations:**
- Enqueue – Inserts an element at the rear.
- Dequeue – Removes an element from the front.
- Peek – Returns the front element.
- Empty – Checks whether the queue is empty.
- Full – Checks whether the queue is full.
- Display – Displays the queue elements.

**Principle:** FIFO (First In, First Out)
